# Data Lists

This directory will contain reproducible dataset split lists. Dataset files and generated placeholder lists are not committed.

Planned lists:

- `train_aug.txt`: VOC 2012 augmented training split.
- `dev_500.txt`: fixed 500-image development subset.
- `train_without_dev.txt`: training split excluding the development subset.
- `val.txt`: validation split.
- `coco_lite_5000.txt`: fixed 5,000-image COCO research subset.
